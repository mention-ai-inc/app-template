# Overview

The product thesis. One page, written before the first PRD and revised when the thesis actually
changes — not when a feature does.

Say what the product is for, who it is for, and what it refuses to be. Every PRD's Problem section
argues back to this page, so it has to contain something a requirement can contradict. A thesis that
nothing could violate is not doing any work.

Keep it short enough that it is read.
